# 🌸 FLOWDAY — 수험생 스터디 플래너

연한 파스텔 톤의 모던한 수험생 스터디 플래너입니다.
D-Day 카운터 · 일간/주간 플래너 · 집중 타이머 · 타임테이블 · 모의고사 타이머를 담았습니다.

모든 데이터는 브라우저(localStorage)에 저장됩니다. 서버가 필요 없어 GitHub Pages로 바로 배포할 수 있어요.

## 기능

- **D-Day** — 시험 이름과 목표일을 수정하면 자동 계산
- **오늘 달성률 / 오늘 공부** — 완료율 도넛, 총 공부 시간, 집중 세션 횟수
- **일간 플래너** — 과목별(국어·수학·영어·탐구) 할 일, 완료 체크, 수정/삭제/순서 이동, 어제 못 끝낸 할 일 자동 이월
- **주간 플래너** — 과목별 주간 목표와 전체 진행률
- **집중 타이머** — 과목 선택 후 세션 시작, 휴식 시간 별도 기록, 공부 종료 시 자동 저장
- **타임테이블** — 요일별 공부량, 06~24시 타임 스트립, 과목별 합계, 기록 수동 편집
- **모의고사 타이머** — 과목별 시험 시간(수정 가능), 원형 카운트다운, 음성 알림(10분/5분/1분 전, 종료)

## GitHub Pages 배포 방법

1. GitHub에서 새 저장소(repository)를 만듭니다. 예: `flowday`
2. 이 폴더의 `index.html`(과 `README.md`)을 업로드합니다.
3. 저장소 **Settings → Pages**로 이동합니다.
4. **Source: Deploy from a branch**, Branch: `main` / `(root)` 선택 후 **Save**.
5. 1~2분 뒤 `https://<아이디>.github.io/flowday/` 에서 사이트가 열립니다.
